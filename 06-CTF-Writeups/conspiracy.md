
# Conspiracy — Encoded Data Investigation

## Challenge Overview

**Competition:** Bits n Bytes CTF 2026  
**Platform:** MetaCTF  
**Category:** Forensics  
**Points:** 350/350  
**Status:** Solved

## Scenario

The challenge presented the
following description:

"They're in the trees!
Behind the bush!
On my stack!
They're everywhere!!"

The objective was to decode
characters contained in a
provided file and recover
the hidden flag.

The supplied artifact was
a PowerShell script:

`conspired.ps1`

## Investigation Scope

The investigation involved
examining an encoded-data
challenge distributed as
a PowerShell script.

Relevant areas of analysis
include:

- Script inspection
- Character encoding
- Data representation
- Pattern recognition
- Decoding techniques

The original decoding algorithm
has not yet been reconstructed.

## Challenge Result

The challenge was successfully
solved, earning 350 points.


## Security Lessons

Scripts may contain data
represented through unusual
encoding schemes.

Understanding data formats
and character transformations
is useful during forensic
investigations.

- Encoded data analysis
