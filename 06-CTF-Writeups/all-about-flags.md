
# All About Flags Binary Analysis Challenge

## Challenge Overview

**Competition:** Bits n Bytes CTF 2026  
**Platform:** MetaCTF  
**Category:** Reverse Engineering  
**Points:** 100/100  
**Status:** Solved

## Scenario

The challenge provided a command-line
application focused on flags.

Both Windows and Linux versions
were available, with equivalent
functionality.

The objective was to investigate
the program and recover the
challenge flag.

## Investigation Scope

The supplied artifact was an
executable application.

Relevant binary investigation
techniques include:

- File identification
- Program behavior analysis
- String inspection
- Input and output analysis
- Static analysis

The exact techniques used in the
original solution have not yet
been confirmed.

## Challenge Result

The challenge was successfully solved,
earning 100 points.

The specific program behavior and
flag recovery method remain to
be reconstructed.

## Security Lessons

Executable analysis can help
investigators understand program
behavior and identify information
embedded in application binaries.

Static and dynamic analysis provide
complementary approaches to
understanding software.

## Skills Demonstrated

- Reverse engineering fundamentals
- Executable investigation
- Technical problem-solving
