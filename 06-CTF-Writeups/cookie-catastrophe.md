
# Cookie Catastrophe Web Security Challenge

## Challenge Overview

**Competition:** Bits n Bytes CTF 2026  
**Platform:** MetaCTF  
**Category:** Web Exploitation  
**Points:** 175/175  
**Status:** Solved

## Scenario

The challenge presented a bakery website
developed by a character named Ash.

The objective was to test the website's
features and identify the security
weakness needed to complete the challenge.

## Investigation Scope

The assessment focused on a web application
provided within the CTF environment.

Relevant areas of web security analysis
include:

- HTTP requests and responses
- Browser session management
- Cookies and client-side state
- Authentication and authorization
- Application behavior

## Challenge Result

The challenge was successfully completed,
earning 175 points.

The exact vulnerability and exploitation
sequence have not yet been reconstructed
from the original investigation.

## Security Lessons

Web applications should enforce security
decisions on the server side rather than
trusting client-controlled information.

Session handling and access control
are important areas of web security
assessment.
