**Platform:** MetaCTF  
**Category:** Forensics

## Scenario

A user named Quinn received a
Halloween-themed invitation.

After saving the invitation,
her computer began displaying
unexpected behavior.

Reported symptoms included:

- Unusual cursor behavior
- Unexpected audio activity
- A modified desktop wallpaper

The challenge provided an artifact
protected with the password:

`infected`

The objective was to investigate
the artifact and determine what
had occurred.

The scenario suggested a possible

interaction with an untrusted file
can indicate a security incident.

Suspicious files should be
investigated in an isolated
analysis environment.

Digital forensic analysis helps
identify the origin and nature
of suspicious activity.
