
# Cloud Pillage Web Security Investigation

## Challenge Overview

**Competition:** Bits n Bytes CTF 2026  
**Platform:** MetaCTF  
**Category:** Web Exploitation  
**Points:** 300/300  
**Status:** Solved

## Scenario

The challenge introduced a startup
named QuestionLink.

The application owner was described
as potentially forgetful, suggesting
that security mistakes might have
been introduced during development.

The challenge included the hint:

"Git to pillaging!"

The objective was to investigate
the website and identify the
security issue.

## Investigation Scope

The challenge involved a web
application hosted in the CTF
environment.

The wording of the scenario suggests
that development artifacts or
repository-related information
could be relevant.

However, the exact weakness
identified during the original
solution has not been verified.

## Challenge Result

The challenge was successfully solved,
earning 300 points.


## Security Lessons

Development artifacts and
configuration mistakes can introduce
security risks when applications
are deployed.

Security reviews should consider
both application functionality
and deployment configuration.
