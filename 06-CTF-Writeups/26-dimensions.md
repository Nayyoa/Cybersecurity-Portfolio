
# 26 Dimensions Reverse Engineering

## Challenge Overview

**Competition:** Bits n Bytes CTF 2026  
**Platform:** MetaCTF  
**Category:** Reverse Engineering  
**Points:** 100/100  
**Status:** Solved

## Scenario

A supercomputing center developed
a program intended to evaluate
physics theories.

The challenge suggested that
the program might not actually
perform the advertised computation.

Instead, the answer could be
hardcoded into the application.

The objective was to determine
the answer hidden in the program.

## Investigation Scope

The challenge involved analyzing
a program to understand how
it produced its output.

Relevant investigation techniques
include:

- Binary inspection
- Static analysis
- Embedded string identification
- Program behavior analysis

The challenge description
specifically suggested looking
for a hardcoded value.

## Result

The challenge was successfully
solved, earning 100 points.

The exact inspection steps
and recovered value have not
yet been reconstructed.

## Security Lessons

Hardcoded information in software
can sometimes be recovered through
static analysis.

Developers should not rely on
hiding sensitive values inside
application binaries.

- Reverse engineering concepts
- Static analysis fundamentals
- Program investigation
- Analytical problem-solving
