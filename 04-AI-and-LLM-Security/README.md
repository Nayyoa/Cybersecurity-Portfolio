
# AI & LLM Security Assessment

## Enterprise Generative AI Security Project

**Organization:** E2IP Technologies  
**Project Type:** Cybersecurity Engineering Internship  
**Focus:** AI Security | Risk Assessment | Security Controls | AI Governance

---

## Project Overview

This project focused on assessing and strengthening the security of Generative AI and Large Language Model usage within an enterprise environment.

The work combined three complementary cybersecurity areas:

1. **AI Security Risk Assessment:** Identifying, analyzing, and mapping security risks associated with enterprise GenAI adoption.
2. **AI Security Solutions Evaluation:** Configuring, testing, and comparing Netskope One AI Security and CrowdStrike security solutions.
3. **AI Governance & Security Awareness:** Developing governance policies, security procedures, and recommendations for responsible AI usage.

The objective was to evaluate technical security controls while establishing a governance framework to help organizations manage AI-related risks.

---

## 1. AI Security Risk Assessment

### Objective

Identify and assess security risks associated with the adoption of Generative AI and LLM-based applications in an enterprise environment.

### Key Activities

- Conducted a security assessment of enterprise GenAI and LLM usage.
- Identified potential threats, vulnerabilities, and data protection risks.
- Analyzed risks related to sensitive data exposure, prompt injection, and unauthorized AI usage.
- Applied the OWASP Top 10 for LLM Applications and NIST AI Risk Management Framework.
- Developed a structured AI security risk mapping approach.
- Documented identified risks and recommended security measures.

### Frameworks

- OWASP Top 10 for LLM Applications
- NIST AI Risk Management Framework (AI RMF)
- NIST AI RMF Generative AI Profile

## 2. Netskope vs. CrowdStrike — AI Security Evaluation

### Objective

Evaluate the effectiveness of enterprise AI security solutions in detecting and mitigating risks associated with GenAI and LLM usage.

### Solutions Evaluated

**Netskope One AI Security**

- Evaluated predefined AI security policies.
- Created and configured custom security policies.
- Tested AI Guardrails and data protection controls.
- Assessed sensitive information detection capabilities.
- Investigated Shadow AI visibility and security controls.
- Analyzed detection results, false positives, and false negatives.

**CrowdStrike AI Security**

- Evaluated AI security capabilities through hands-on testing.
- Configured and tested security policies.
- Created and assessed custom security configurations.
- Analyzed detection results and policy effectiveness.
- Investigated false positives and false negatives.
- Documented findings and technical observations.

### Evaluation Criteria

The evaluation focused on:

- Security policy configuration and customization
- Sensitive data protection
- AI security controls
- Threat and risk detection
- Detection accuracy
- False positives and false negatives
- Operational visibility
- Security monitoring capabilities

## 3. AI Governance & Security Awareness

### Objective

Develop a structured governance approach to support secure and responsible enterprise adoption of Generative AI.

### Key Activities

- Developed an AI Acceptable Use Policy.
- Defined AI data protection and confidentiality guidelines.
- Documented an AI security incident response procedure.
- Established governance roles and responsibilities using a RACI matrix.
- Prepared AI security awareness recommendations.
- Developed an AI governance roadmap and monitoring recommendations.
- Aligned governance recommendations with recognized AI security and risk management frameworks.

### Governance Deliverables

| Deliverable | Purpose |
|---|---|
| AI Acceptable Use Policy | Define authorized, restricted, and prohibited AI usage |
| AI Data Protection Guidelines | Protect confidential and sensitive information |
| AI Security Incident Response Procedure | Establish a process for handling AI-related security incidents |
| AI Governance RACI Matrix | Define roles and responsibilities |
| AI Security Awareness | Promote secure AI usage among employees |
| AI Governance Roadmap | Structure future governance improvements |
